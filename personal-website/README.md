# Vite + React Three Fiber portfolio for kenfoss.com

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output lands in `dist/` (was `build/` under CRA).

## Serve production build locally

```bash
npm run build
npm run serve
```

Express serves `dist/` on port `8850` (or `REACT_APP_LOCAL_PORT` / `PORT`).
